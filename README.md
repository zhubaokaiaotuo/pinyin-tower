# 拼字奇兵

一个用拼音拼字打敌将的小游戏。给一二年级正在学拼音、学识字的孩子用：把字母拼成音节，选对声调，字才会出现；拼出的字变成火苗打向敌将，三个字打倒一个对手。

单文件网页游戏，**双击 index.html 就能玩**，不联网、不安装、不上传任何数据，手机和电脑都能打开。

## 怎么玩

1. 下排八个字母格，点两个或三个字母拼成一个音节（如 zh + i → zhi）
2. 音节下面列出这个音真实存在的声调，**选对声调**才出字（这是练"哪个字是几声"的地方）
3. 拼出的字进我方字格，同时变成火苗打向敌将
4. 单字是小兵（1 点伤害），凑成两字词是营长（2 点），四字成语是大将军（3 点）
5. 敌将和我方各 3 点血，谁先掉光谁输；连胜 5 场封「常胜将军」

## 一些设计上的取舍

- **1-5 关不求快**，只让孩子摸熟"看调、拼字母、点字"这套动作
- **第 6 关起，对手照孩子自己的拼字速度配**：拼得慢就配慢对手，拼得快就配快对手，同时掉血会让对手松一档，不会一路被打到放弃
- **字库从常用字过渡到生僻字**，按统编版语文一到四年级写字表分级，不生造字音
- 木牌、字格、音效全部程序生成，没有外部图片和音频文件

## 技术说明

- 单个 HTML 文件，Canvas 2D 绘制，零外部依赖
- 进度只存在本机浏览器（localStorage），不上传、不收集任何信息
- 音效由 Web Audio 现场合成

## 说明

家庭自用的练习小游戏，供学习和交流使用。字库以统编版小学语文教材写字表为基础整理，如有字音错漏欢迎指出。
