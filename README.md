# 拼好兵

一个用拼音拼字打敌将的小游戏。给一二年级正在学拼音、学识字的孩子用：把字母拼成音节，选对声调，字才会出现；拼出的字变成火苗打向敌将，三个字打倒一个对手。

单文件网页游戏，**双击 index.html 就能玩**，不联网、不安装、不上传任何数据，手机和电脑都能打开。

## 怎么玩

1. 首页选版本：**蒙学**慢慢来、以认字为主；**会试**上手就快、每关计时比拼速度；**殿试**硬核原味、破关不补血，只给真正的将军
2. 下排八个字母格，点两个字母拼成一个音节（如 zh + i → zhi）；三拼音节用**介韵卡**拼（j + ian → jian），介母和韵母合在一张卡上，不会半路拼错
3. 音节下面列出这个音真实存在的声调，**选对声调**才出字（这是练"哪个字是几声"的地方）
4. 拼出的字进我方字格，同时变成火苗打向敌将
5. 单字是小兵，凑成两字词是**营长**，四字成语是**大将军**：
   - 蒙学：小兵打 1 格、营长打 2 格、大将军一次打 3 格（敌将共 3 格，老手感）
   - 会试 / 殿试：敌将共 3 大格——**5 个小兵打掉一格、3 个营长打掉一格、1 个大将军一次打掉一格**，一关要真刀真枪打个十几回合
6. 敌将和我方各 3 大格血，谁先掉光谁输；连胜 5 场封「常胜将军」
7. **每 20 关升一级军阶**，小人会真的换装：小兵（1–19 关，光头木棍）→ 伍长（20 关，头巾短甲短刀）→ 百户（40 关，铁盔披风长矛）→ 千户（60 关，金盔长缨鳞甲）→ 将军（80 关，双翎护心镜大氅）。升职当关全场报喜，敌将也同步升档
8. **开局选一员三国名将代表自己**：蜀魏吴董四个阵营 20 员将（赵云、张辽、周瑜、吕布……），脚下写名字、阵营带颜色；敌将每关从别家阵营里换人出战。破关、败北的结算页都能**返回首页**，局内右上角「回营」按两下也能回
9. **关卡进度永久保留，退出不白打**：蒙学／会试打通的关卡会记在本机，首页「开战」按钮直接写着「开战 · 第 X 关」，退出、输一局、点再战都从这一关接着打，绝不回到第 1 关（殿试保持原味，每局都从第 1 关起）。同一局没打完就退出，首页还会亮出「续战 · 第 X 关」，连剩余血量和连胜一起接上；败北后该局存档清掉，成绩（最高分/称号/已学字）始终保留。**历史最远关卡单独记档**（按版本分开、败北不清），首页统计行显示「最远第 X 关」，并按阵营记下「谁打出来的」，给以后阵营选代表当参考

## 一些设计上的取舍

- **军阶用同一副简笔骨架叠装备**：不是换贴图，而是按等级一层层往上画，学 80 年代美影厂动画（神笔马良、九色鹿那种）单线勾边、色块平涂的味道——升级看得见，画又不是照搬贴纸
- **三个版本分开记成绩**：蒙学、会试、殿试的最高分、连胜、称号互不干扰
- **会试/殿试强化词语和成语**：从第 1 关起，字母栏和木牌会经常送来「能和我方字格组词」的字，字格里已有成语的字时还会补上缺的那个字——大将军不用靠运气
- **蒙学每破一关补 1 条命**，选错字不加速木牌——认字阶段不拿速度惩罚孩子；会试破关回 1 格、打掉敌将一整格血也回 1 格（压制回气），选错木牌变快；殿试破关不补血，最快出牌间隔压到人体反应临界点 0.9 秒
- **介韵卡**：三拼音节（jian/guan/xiao）的韵母以整体形式出现（ian/uan/iao），和教材一致，孩子不会拼到一半走出岔路
- **字库从常用字过渡到生僻字**，按统编版语文一到四年级写字表分级，不生造字音
- 木牌、字格、音效全部程序生成，没有外部图片和音频文件

### 其他

- **对手照玩家自己的拼字速度配**：拼得慢就配慢对手，拼得快就配快对手，同时掉血会让对手松一档，不会一路被打到放弃（会试从第 4 关起按手速配，并以实测「平均 3.2 秒/字」为标准档；殿试只在硬核边界内微调）

## 技术说明

- 单个 HTML 文件，Canvas 2D 绘制，零外部依赖
- 进度只存在本机浏览器（localStorage），不上传、不收集任何信息
- 音效由 Web Audio 现场合成

## 说明

家庭自用的练习小游戏，供学习和交流使用。字库以统编版小学语文教材写字表为基础整理，如有字音错漏欢迎指出。
